API Changelog 1.0.29-SNAPSHOT vs. 1.0.17
API Changes
POST /pet
Updated
  • added the non-success response with the status `405`
  • removed the non-success response with the status `400`
  • removed the non-success response with the status `422`
PUT /pet
Updated
  • added the non-success response with the status `405`
  • removed the non-success response with the status `422`
GET /pet/findByStatus
Updated
  • the `query` request parameter `status` became optional
GET /pet/findByTags
Updated
  • the `query` request parameter `tags` became optional
DELETE /pet/{petId}
Updated
  • removed the success response with the status `200`
POST /pet/{petId}
Updated
  • removed the success response with the status `200`
  • added the non-success response with the status `405`
  • removed the non-success response with the status `400`
POST /pet/{petId}/uploadImage
Updated
  • removed the non-success response with the status `400`
  • removed the non-success response with the status `404`
POST /store/order
Updated
  • added the non-success response with the status `405`
  • removed the non-success response with the status `400`
  • removed the non-success response with the status `422`
DELETE /store/order/{orderId}
Updated
  • removed the success response with the status `200`
POST /user
Updated
  • removed the success response with the status `200`
  • added the media type `application/json` for the response with the status `default`
  • added the media type `application/xml` for the response with the status `default`
GET /user/logout
Updated
  • removed the success response with the status `200`
DELETE /user/{username}
Updated
  • removed the success response with the status `200`
PUT /user/{username}
Updated
  • removed the success response with the status `200`
  • removed the non-success response with the status `400`
  • removed the non-success response with the status `404`
components
  • the component security scheme `petstore_auth` oauth url changed from `https://petstore3.swagger.io/oauth/authorize` to `https://petstore.swagger.io/oauth/authorize`
info
  • a breaking change was detected but the version decreased from `1.0.29-SNAPSHOT` to `1.0.17`

Schemathesis: тесты, которые пишет сама OpenAPI-спецификация

Schemathesis: tests written by the OpenAPI spec itself

Инструмент читает описание API, сам генерирует тысячи запросов, включая заведомо неправильные, и проверяет каждый ответ на соответствие той же спецификации. Здесь он гоняет копию Swagger Petstore в Docker.

The tool reads the API description, generates thousands of requests (deliberately broken ones included) and checks every response against that same spec. Here it runs against a private Swagger Petstore in Docker.
